✨ Features

Dual Prayer Engines
PrayTimes.js v2.3 + Adhan.js v4.4.3 with side-by-side comparison mode. 8 calculation methods + custom angles.

Real-time countdown to next prayer with auto-advance through the day. Prayer icon + name display.

Per-prayer ±30 min offsets to match your local mosque. Mawaqit direct link integration.

🚀 Quick Start

Web App

  1. Clone the repo: git clone https://github.com/abourdim/salat-times.git
  2. Open index.html in Chrome or Edge
  3. Grant location access for accurate times (optional — defaults to Chelles, FR)

Or visit: abourdim.github.io/salat-times

Adhan Lantern (micro:bit V2)

  1. Go to makecode.microbit.org
  2. New project → add Bluetooth extension
  3. Switch to TypeScript editor
  4. Paste contents of adhan-lantern.ts
  5. Project Settings → No Pairing Required = ON
  6. Download → drag .hex to MICROBIT drive
  7. Open the web app in Chrome → click 🏮 Connect Lantern

📡 BLE Protocol

Communication via Nordic UART Service (NUS) over Bluetooth Low Energy.

App → micro:bit

CommandExampleDescription
HELLOHELLOHandshake after connect
TIMES:TIMES:F06:43|S07:53|D13:03|A15:45|M18:15|I19:24|N=A|T=84Full prayer time sync
ALERT:ALERT:APrayer time reached — trigger adhan

Prayer codes: F=Fajr, S=Sunrise, D=Dhuhr, A=Asr, M=Maghrib, I=Isha

micro:bit → App

ResponseDescription
READYFirmware acknowledged HELLO
BTN:AButton A pressed
BTN:BButton B pressed
TOUCHLogo touched

🛡️ Hardening

Graceful Degradation
Map init wrapped in try/catch. App works fully without Leaflet, without GPS, without BLE.
API Failover
Overpass mirror fallback. response.ok checks on all fetches. Debounced mosque loading.
XSS Protection
HTML sanitizer esc() on all mosque names from Overpass before DOM insertion.
BLE Stability
Sequential write queue prevents GATT collisions. Auto-reconnect. Queue cleared on disconnect.
